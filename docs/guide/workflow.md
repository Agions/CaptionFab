# 使用流程

CaptionFab 采用「导入 → 选区 → 识别 → 导出」的四步工作流，最小化用户操作。

---

## 完整流程

```mermaid
graph LR
  A[导入视频] --> B[选择 ROI]
  B --> C[配置 OCR]
  C --> D[开始提取]
  D --> E[导出字幕]
```

---

## 1. 导入视频

支持的格式：MP4 · MKV · AVI · MOV · WebM · M4V · WMV · FLV · 3GP

- 点击「文件」标签页或直接拖拽视频到窗口
- 系统自动读取视频元数据：分辨率、帧率、时长、编码

**提示：** 视频文件越大，提取时间越长。建议先使用场景检测跳过无字幕帧。

---

## 2. 选择 ROI（感兴趣区域）

ROI 用于限定 OCR 识别区域，减少误识别和计算量。

### 预设区域

| 预设 | 说明 | 适用场景 |
|:-----|:-----|:---------|
| 底部字幕 | 最常见，y=85%, h=15% | 大多数视频 |
| 顶部字幕 | y=0%, h=15% | 片头/片尾标题 |
| 左侧字幕 | x=0%, w=40%, y=30%, h=40% | 竖屏或双语左对齐 |
| 右侧字幕 | x=60%, w=40%, y=30%, h=40% | 双语右对齐 |
| 中间字幕 | x=20%, w=60%, y=40%, h=20% | 居中字幕 |

### 自定义选区

- 在视频预览区拖拽绘制矩形区域
- 支持像素或百分比单位切换
- 选区会自动吸附到字幕常见位置

**优化：** 拖拽时采用 rAF 直写 DOM，绕过 Vue 响应式，确保 60fps 流畅度。

---

## 3. 配置 OCR

### OCR 引擎

| 引擎 | 技术 | 速度 | 准确率 | 语言 |
|:-----|:-----|:-----|:------|:-----|
| PaddleOCR | 深度学习 | 快 | 高 | 80+ |
| EasyOCR | 深度学习 | 中 | 高 | 40+ |
| Tesseract | 传统算法 | 慢 | 中 | 100+ |

### 处理模式

| 模式 | 跳帧 | 多通道 | 场景阈值 | 置信度阈值 | 适用场景 |
|:-----|:-----|:-------|:---------|:-----------|:---------|
| 快速模式 | 3 帧 | 否 | 0.4 | 0.6 | 预览或粗提取 |
| 标准模式 | 2 帧 | 否 | 0.3 | 0.5 | 日常使用（推荐） |
| 精准模式 | 1 帧 | 是 | 0.2 | 0.4 | 高质量提取 |

### 高级选项

- **多通道 OCR**：对同一帧多次识别，合并结果提升准确率
- **后处理**：启用 Pipeline 去噪和合并
- **AI 校正**：调用 LLM 校正 OCR 错误（可选）
- **场景检测**：自动跳过无字幕帧，减少 60% 无效 OCR

---

## 4. 开始提取

点击「开始提取」后，系统进入提取循环：

```
for each frame:
  ├─ 跳过静音帧（ROI 空帧检测）
  ├─ 场景变化检测（直方图 + 卡方检验）
  ├─ 捕获帧 → 预处理 → OCR 识别
  ├─ 置信度校准（CJK n-gram + 竖线检测）
  └─ 更新进度条
```

**性能优化：**
- 提取循环中使用 `requestAnimationFrame` 节流，避免阻塞 UI
- 256 帧 LRU 缓存，相同帧不重复识别
- 暂停/恢复机制，支持长时间任务

---

## 5. 导出字幕

提取完成后，进入「导出」标签页：

### 导出格式

| 格式 | 扩展名 | 说明 |
|:-----|:-------|:-----|
| SubRip | `.srt` | 最通用，YouTube、Premiere 支持 |
| WebVTT | `.vtt` | 网页视频、HTML5 标准 |
| ASS/SSA | `.ass` / `.ssa` | 高级字幕，支持样式和特效 |
| JSON | `.json` | 结构化数据，二次开发友好 |
| CSV | `.csv` | 表格数据，Excel 打开 |
| TXT | `.txt` | 纯文本，仅对白 |
| LRC | `.lrc` | 音乐歌词格式 |
| SBV | `.sbv` | YouTube 批量上传格式 |

### 导出选项

- **编码**：UTF-8（默认）、GBK（Windows 兼容）
- **帧率**：自动检测或手动指定
- **双语导出**：原文 + 翻译对照（可选）

---

## 最佳实践

1. **先用快速模式预览**：确认 ROI 和处理参数
2. **再使用标准模式提取**：平衡速度和准确率
3. **关键视频使用精准模式**：确保每个字幕都被识别
4. **启用场景检测**：显著减少处理时间
5. **导出后检查**：人工校验低置信度字幕
