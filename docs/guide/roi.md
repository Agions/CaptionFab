# ROI 配置

ROI（Region of Interest，感兴趣区域）用于限定 OCR 识别范围，提升准确率和速度。

---

## 概念

ROI 是一个矩形区域，定义视频帧中需要 OCR 识别的部分。通过限制识别范围，可以：

1. **减少误识别**：排除视频其他区域的干扰
2. **提升速度**：只处理必要像素
3. **降低 GPU 负载**：减少预处理和推理开销

---

## 预设 ROI

CaptionFab 提供 5 个常用预设，覆盖大多数视频字幕布局：

| 预设 | 坐标 (x, y, w, h) | 单位 | 适用场景 |
|:-----|:------------------|:-----|:---------|
| 底部字幕 | 0%, 85%, 100%, 15% | percent | 大多数视频 |
| 顶部字幕 | 0%, 0%, 100%, 15% | percent | 片头/片尾标题 |
| 左侧字幕 | 0%, 30%, 40%, 40% | percent | 竖屏或双语左对齐 |
| 右侧字幕 | 60%, 30%, 40%, 40% | percent | 双语右对齐 |
| 中间字幕 | 20%, 40%, 60%, 20% | percent | 居中字幕 |

**单位说明：**
- `percent`：百分比，相对于视频分辨率
- `pixel`：像素，绝对坐标

---

## 自定义 ROI

### 拖拽绘制

1. 在视频预览区按住鼠标左键
2. 拖拽绘制矩形区域
3. 松开鼠标完成选区

**优化：** 拖拽时采用 rAF 节流 + 直接 DOM 写入，确保 60fps 流畅度。

### 参数调整

在 ROI 标签页中可精确调整：

- **X / Y**：左上角坐标
- **Width / Height**：宽度和高度
- **Unit**：切换 percent / pixel

### 预览

调整 ROI 后，视频预览区会显示半透明遮罩，突出显示识别区域。

---

## ROI 预检测

CaptionFab 在提取前会进行 ROI 预检测，跳过全黑/低方差帧：

```typescript
function isRoiRegionLikelyEmpty(
  frameData: ImageData,
  roi: ROI,
  threshold = 100,
): boolean {
  const metrics = extractFrameMetrics(frameData, roi)
  return metrics.variance < threshold
}
```

**效果：** 减少 30-60% 无效 OCR 调用。

---

## 最佳实践

1. **精确选区**：ROI 越小越好，只包含字幕区域
2. **避开干扰**：排除滚动条、水印、字幕条背景
3. **预留边距**：上下各留 5-10% 边距，应对字幕跳动
4. **测试验证**：先用快速模式验证 ROI 是否准确
5. **多 ROI 切换**：不同视频使用不同预设

## 常见问题

**Q: ROI 选区不准确怎么办？**

A: 尝试以下方法：
1. 切换到 pixel 单位，精确调整坐标
2. 在视频播放时动态调整 ROI
3. 使用底部字幕预设，再微调

**Q: 为什么有些帧没有识别到字幕？**

A: 可能原因：
1. ROI 区域未覆盖字幕实际位置
2. 字幕颜色与背景太接近
3. 视频分辨率过低

**Q: ROI 预检测误跳过字幕帧？**

A: 降低 `threshold` 参数（默认 100），或关闭预检测功能。
