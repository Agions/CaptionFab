# 键盘快捷键

CaptionFab 提供完整的键盘快捷键支持，提升操作效率。

---

## 全局快捷键

| 快捷键 | 功能 | 说明 |
|:-------|:-----|:-----|
| `Space` | 播放/暂停 | 控制视频播放 |
| `←` / `→` | 后退/前进 1 帧 | 逐帧精确定位 |
| `↑` / `↓` | 增加/减少音量 | 每次 10% |
| `M` | 静音切换 | 快速静音 |
| `Home` | 跳到首帧 | 快速回到开头 |
| `End` | 跳到末帧 | 快速跳到结尾 |
| `Esc` | 取消选择 | 清除当前选区 |

---

## 时间轴快捷键

| 快捷键 | 功能 | 说明 |
|:-------|:-----|:-----|
| `←` / `→` | 跳转到上/下一条字幕 | 在时间轴聚焦时有效 |
| `Enter` / `Space` | 播放/定位到选中字幕 | 选中后跳转 |
| `Home` | 跳到第一条字幕 | |
| `End` | 跳到最后一条字幕 | |
| `Esc` | 取消时间轴聚焦 | |

---

## 批量处理快捷键

| 快捷键 | 功能 | 说明 |
|:-------|:-----|:-----|
| `Ctrl/Cmd + A` | 全选 | 选择所有任务 |
| `Ctrl/Cmd + D` | 取消全选 | 清除选择 |
| `Delete` | 删除选中 | 删除选中任务 |
| `Ctrl/Cmd + E` | 导出选中 | 导出选中任务结果 |

---

## 自定义快捷键

目前不支持自定义快捷键。如有需求，请提交 Issue。

---

## 快捷键冲突

如果快捷键与其他软件冲突，可以：
1. 关闭 CaptionFab 后使用其他软件
2. 最小化 CaptionFab 窗口

---

## 技巧

- 在时间轴上按 `←` / `→` 可快速浏览字幕
- 按 `Space` 播放视频，自动同步时间轴
- 使用 `Home` / `End` 快速跳转到视频开头/结尾
