# OCR 引擎

CaptionFab 支持三种 OCR 引擎，可根据语言、速度和准确率需求选择。

---

## 引擎对比

| 引擎 | 技术 | 速度 | 准确率 | 语言数 | GPU 加速 | 本地运行 |
|:-----|:-----|:-----|:------|:-------|:---------|:---------|
| PaddleOCR | 深度学习 | ⚡⚡⚡ | ⭐⭐⭐⭐ | 80+ | ✅ | ✅ |
| EasyOCR | 深度学习 | ⚡⚡ | ⭐⭐⭐⭐ | 40+ | ✅ | ✅ |
| Tesseract | 传统算法 | ⚡ | ⭐⭐⭐ | 100+ | ❌ | ✅ |

**推荐：** 中文/英文/多语言场景优先使用 PaddleOCR，纯英文可考虑 EasyOCR，小语种可尝试 Tesseract。

---

## PaddleOCR

### 概述

PaddleOCR 是百度飞桨团队开源的 OCR 工具包，基于深度学习，在中文场景表现优异。

### 优势

- **中文准确率最高**：针对 CJK 字符优化，准确率 95%+
- **轻量模型**：PP-OCRv6 模型大小适中，推理速度快
- **多语言支持**：80+ 语言，覆盖主流语种
- **GPU 加速**：ONNX Runtime 推理，支持 CUDA / Metal

### 配置

```yaml
ocr:
  engine: paddle
  language: ch
  confidenceThreshold: 0.5
```

### 支持语言

中文、英文、日文、韩文、法文、德文、西班牙文、葡萄牙文、俄文、阿拉伯文等 80+。

---

## EasyOCR

### 概述

EasyOCR 基于 PyTorch 的深度学习 OCR 引擎，支持多语言混合识别。

### 优势

- **多语言混合**：单次识别可检测多种语言
- **简单易用**：API 简洁，无需复杂配置
- **GPU 加速**：支持 CUDA 加速

### 劣势

- **模型较大**：首次下载需 100MB+
- **速度较慢**：相比 PaddleOCR 略慢

### 配置

```yaml
ocr:
  engine: easyocr
  language: en
  confidenceThreshold: 0.5
```

### 支持语言

英文、中文、日文、韩文、法文、德文、西班牙文等 40+。

---

## Tesseract

### 概述

Tesseract 是 Google 维护的传统 OCR 引擎，基于形态学和规则。

### 优势

- **语言最全**：100+ 语言支持
- **无需 GPU**：纯 CPU 运行
- **轻量**：模型文件小，启动快

### 劣势

- **准确率较低**：对复杂背景、艺术字识别效果差
- **速度慢**：无 GPU 加速
- **中文效果不佳**：相比深度学习引擎差距明显

### 配置

```yaml
ocr:
  engine: tesseract
  language: eng
  confidenceThreshold: 0.5
```

### 支持语言

100+ 语言，包括中文简繁体、英文、日文、韩文等。

## 性能优化

### 缓存策略

CaptionFab 使用 256 帧 LRU 缓存，相同帧不重复识别：

```typescript
const cache = new LRUCache<string, OCRResult>(256)
```

### 跳帧策略

- **快速模式**：每 3 帧识别一次
- **标准模式**：每 2 帧识别一次
- **精准模式**：逐帧识别

### 预处理优化

- ROI 预检测：跳过全黑/低方差帧
- 场景检测：自动跳过无字幕帧，减少 60% 无效 OCR

## 常见问题

**Q: PaddleOCR 首次加载很慢？**

A: 首次运行会自动下载 ONNX 模型（约 10MB），后续会缓存到本地。

**Q: 如何提高识别准确率？**

A:
1. 精确调整 ROI 区域，只包含字幕区域
2. 使用标准模式或精准模式
3. 启用后处理管道去噪
4. 对低置信度结果启用 AI 校正

**Q: GPU 加速无效？**

A: 请确保已安装 CUDA 驱动，且 ONNX Runtime 使用 CUDA 执行提供程序。

**Q: 识别结果有误？**

A: 检查以下几点：
1. ROI 是否包含过多背景
2. 视频分辨率是否过低
3. 字幕是否有特殊字体或特效
4. 尝试切换其他 OCR 引擎
